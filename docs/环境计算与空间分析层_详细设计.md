# 环境计算与空间分析层：详细设计

日期：2026-09-16；版本：v0.1；状态：设计草案，尚未实现或验证。

本层属于[五层架构](系统分层与模块架构.md)的第三层。输入由接入层规范化并版本化，输出供应用接口查询及前端展示。太阳辐射算法以[物理降尺度方案](太阳辐射物理降尺度方案.md)为具体依据。

## 1. 模块与输入输出

| 模块 | 必要输入 | 输出 | 重算条件 |
| --- | --- | --- | --- |
| C01 背景气象处理 | 查询点坐标、逐小时温湿风等、单位、有效时间和批次 | 变量背景场、有效掩膜、查询支持数据 | 气象批次、点集或处理方法变化 |
| C02 场景计算准备 | 建筑、树冠、地形、水平与垂直基准、高度来源 | 米制计算几何、接收点、空间索引、覆盖及质量标识 | 几何、坐标转换或接收点配置变化 |
| C03 太阳与直射遮挡 | 场景几何、位置、时刻、树冠透射方案 | 太阳位置、不透明可见系数、有效太阳透射系数 | 目标时刻、几何或透射方案变化 |
| C04 天空因子 | 场景几何、半球采样方案、树冠透射方案 | 几何 SVF、有效天空透射因子及采样配置 | 几何、透射或采样方案变化 |
| C05 局地短波计算 | 合格的 DNI/DHI 或可分解 GHI、C03/C04 结果 | 水平接收面局地下行短波估计 | 辐射背景、几何计算或模型参数变化 |
| C06 体感环境匹配 | UGC 位置、精度、体验时间及对应环境版本 | 匹配数值、质量、来源与失败原因 | 新打卡、打卡修订或显式重新配对 |
| C07 成果校验与发布 | 上述计算成果、依赖清单与检查结果 | 不可变结果清单及当前可用版本引用 | 新任务完成并通过检查 |

C02—C04 可以在缺少辐射数据时独立运行。C05 不满足物理输入条件时标为不可用，不能借用净短波背景乘阴影系数补出局地辐照度。

## 2. 统一结果契约

以下为拟定的结果语义，不是已建数据库字段。数据库与 API 细化阶段据此落定结构。

| 信息 | 必须表达的内容 |
| --- | --- |
| 身份与依赖 | 产品、结果版本、各输入版本、代码及参数版本 |
| 物理定义 | 变量、单位、接收高度/方向、瞬时或区间平均/累计 |
| 时间 | 有效时刻或区间、预报发布时间（如已知）、获取时间、计算时间 |
| 空间 | CRS、输出范围、有效掩膜、计算网格、来源采样间距及已知位置误差 |
| 方法 | 插值或物理模型、假设、缺省参数、反射等省略项 |
| 质量 | 正常、缺失、不兼容、覆盖不足、输入过期等状态与原因 |

有效数值与质量标识分别保存。风速零可能是真实静风；无风数据必须为空。质量等级不能在没有校准依据时转换为统计置信区间。

服务端统一 UTC，界面按 Asia/Shanghai 展示。空间计算使用 EPSG:32651，坐标交换使用 EPSG:4326；输入含 GCJ-02 时实际转换并记录，不能仅更换 CRS 标签。

## 3. 背景气象计算

约 1 km 是请求点间距，不能推定供应商具有相同分辨率。相邻请求返回同一模式格点时保留该关系，不视为独立观测。

首版对规则点阵内的适用连续变量采用双线性空间估计，四角必须有同一产品批次、同一有效时刻的有效值。支持不全时输出缺测，不向点集以外无限外推。具体规则沿用[实时气象设计](实时气象视图_详细设计.md)。

风先按核验的气象风向约定转为东西/南北分量，插值后还原。温度、相对湿度和露点进行物理一致性检查；如采用水汽变量推导湿度或露点，注明派生方法并保留供应商原值。

“现在”优先使用明确标时的有效小时数据；启用分钟时间插值时需要前后时刻支持，仅用于适用连续变量。不得对天气类别或累计降水直接做同样处理。

## 4. 局地辐射计算

### 4.1 能力分支

| 已核验输入 | 可发布产品 |
| --- | --- |
| 只有净短波 | 区域净短波背景、独立的几何遮挡和天空因子 |
| 匹配的 GHI | 在适用分解方法及时间语义成立时，估计直散分量后计算局地下行短波 |
| 匹配的 DNI/DHI | 结合投影、直射透射和有效天空因子计算局地下行短波 |

未知变量定义或时间语义时先停在输入核验阶段。仅有净短波的反演例外条件以降尺度方案为准，不默认启用。首版如省略周边反射，产品名称与元数据明确说明。

### 4.2 几何与时间

在数据完整的小样区从 10—30 m 接收网格起步，具体边界尚待确定。网格间距是计算设置，准确度需独立观测评估。建筑内部点、几何覆盖不足及远处遮挡未知区域按情况剔除或标记。

背景为小时平均辐射时，小时内按候选 10 分钟子步计算太阳投影与遮挡后积分平均，并通过更细步长检查收敛。屏幕实时光影单独更新，不能让瞬时阴影被标为小时平均结果。

几何 SVF 与包含树冠透射的有效天空因子分别定义，避免重复扣减树冠遮挡。地面和行人高度水平探针分别命名；二者均不是人体六方向辐射模型。

## 5. 体感与环境匹配

匹配使用体验时间，不使用提交时间替代。先检查位置来源、精度、室内外和时间不确定性，再查询当时覆盖范围内的环境版本。

- 数据库保留原始体验和环境配对两类记录，环境不可用不阻止打卡保存。
- 室内打卡可关联室外背景作环境语境，但不能标成室内温度或辐射暴露。
- 位置误差大于局地变化尺度时，标为不能精确判定树荫/日晒；需要时对误差范围计算分布，不能只取中心点后声称精确匹配。
- 找不到体验时刻对应的已归档环境数据时，保持未匹配，不用现在的预报替代过去环境。
- 地点或体验时间修改后生成新匹配修订；重新分析记录所用的新环境版本，避免悄悄覆盖旧配对。

历史社媒热表达模型与新 UGC 自报量表分别管理，未核验量表可比性和迁移性能前不直接套用。该模型不能用于修正客观温度。

## 6. 调度、缓存与发布

任务去重键包含模块、输入版本、区域、目标时间/区间、网格和参数版本。重复请求复用已有任务或成果；失败重试有次数限制，不由鼠标移动触发计算。

缓存依赖分开维护：静态几何索引依赖场景；天空因子另依赖树冠与采样设置；太阳透射另依赖时刻；最终辐射再依赖气象背景。气象更新时可复用未变化的几何结果。

任务状态为待执行、计算中、成功、失败或输入不满足。输入不满足需等待输入变化，不进行无意义自动重试。多个任务乱序完成时，发布器按源批次与有效范围核验，避免较旧输入的迟到任务覆盖新结果。

成果先写临时位置，通过结构、掩膜、范围与依赖检查后发布不可变结果清单，再原子更新可用版本引用。旧版保留用于已打开页面与 UGC 追溯；保留期限与存储配额在存储设计中确定。

一个产品的渲染与点查询绑定同一结果版本。跨产品合成必须核验时间、覆盖及物理定义兼容；各层独立显示时允许版本不同，但需分别说明有效时间。

## 7. 首版验收与边界

| 验收项 | 可复核要求 |
| --- | --- |
| 气象处理 | 原请求点取值与源记录一致；跨 0° 风向处理正确；缺测不填零 |
| 辐射输入 | 净短波单独存在时拒绝直接生成局地下行短波 |
| 遮挡与天空 | 已知简单几何下的太阳可见性正确；天空因子在合理范围内且采样收敛 |
| 时间 | 小时均值与瞬时结果区分；UTC/上海时间和跨日匹配一致 |
| 发布 | 新结果未就绪不替换旧版；地图与读数同版；旧任务不覆盖新批次 |
| UGC | 缺失环境仍可打卡；修改后可追溯配对；室内记录不冒充室外暴露 |
| 精度评估 | 有独立辐射观测时，以相同物理量和平均区间比较误差；无观测时只报告数值与流程验证 |

本轮仅形成模块设计。UTCI、完整 Tmrt、街谷风场和建筑引起的局地气温变化尚未具备实现与验证结论；后续输入齐备时按独立模块扩展。
