# 无需认证的公开气象数据获取测试

日期：2026-09-16。这里“无需验证”按无需账户、登录或API Key理解，不表示无需科学质量验证。本次仅做小规模获取测试，没有计算UTCI或接入前端实时服务。

## 实测结果

测试地点：上海市中心附近，纬度31.2304、经度121.4737，WGS84。请求使用UTC时间、风速m/s，保存原始响应，未提供密钥。

| 数据源 | 实测结果 | 获取内容 |
| --- | --- | --- |
| Open-Meteo，指定gfs_seamless | 成功 | 48小时数据，8个请求变量各48个非空值，以及current温湿风 |
| Open-Meteo，指定ecmwf_ifs025 | 成功 | 48小时数据，8个请求变量各48个非空值，以及current温湿风 |
| NOAA GFS公开S3直连 | 失败，HTTP 404；重试仍为404 | 失败位于可用日期目录查询，未取得索引或GRIB数据 |

两份成功数据的小时窗口均为2026-09-16 00:00至09-17 23:00 UTC。返回current时间为2026-09-16 01:00 UTC，即北京时间09:00，interval=900秒。这是返回值的时间间隔，不能据此认定原始预报模型每15分钟更新一次。

取得的小时变量：2 m气温（℃）、2 m相对湿度（%）、10 m风速（m/s）、10 m风向（°）、总短波、水平直射、散射、法向直射辐射（W/m²）。必须继续核实各模型字段的原生/派生性质和辐射时间口径。

失败端点：`https://noaa-gfs-bdp.s3.amazonaws.com/?list-type=2&prefix=gfs.&delimiter=/`。404只能说明本机本次请求未成功，不能据此断言GFS产品不存在、一定需要账号或其他渠道也不可用。脚本为成功列目录后的流程准备了6个GRIB变量消息的按字节范围下载，本次该阶段未执行。

## 脚本与运行

脚本：[scripts/probe_public_weather.py](../scripts/probe_public_weather.py)。使用已有Python环境的requests，不需要新安装依赖。

在项目根目录运行：

```powershell
.venv/Scripts/python.exe scripts/probe_public_weather.py
```

只测试已成功的两个接口：

```powershell
.venv/Scripts/python.exe scripts/probe_public_weather.py --sources open_meteo_gfs open_meteo_ecmwf
```

可用参数包括 `--latitude`、`--longitude`、`--timeout`、`--sources`、`--max-message-bytes`、`--output`。默认输出到新建的 `data/derived/public_weather_probe_<时间>/`；拒绝覆盖已有目录。未来运行的预报日期随服务时间变化，不固定为本次日期。

网络请求有超时及响应大小限制。NOAA流程只尝试最多最近3个可列出的日期，目标是f003的TMP、RH、UGRD、VGRD、DSWRF、DLWRF消息；单个消息默认上限5 MB，服务器不接受Range请求时不会下载整个大型文件。单个源失败不阻止后续源，失败状态写入清单；部分成功不能当作所有源成功。

## 原始响应与清单结构

本部分结构说明在平台目录内独立维护，不同步到项目数据字典。Open-Meteo原始JSON保留 `hourly.time`、各变量数组及 `hourly_units`，按相同数组下标关联；原始null保留，不填0。`current.time/interval`表示代表时间与间隔，不是模型起报时间或更新频率。接口返回位置不证明模型原生分辨率。

清单 `results[]` 按源记录success/partial/failed，`request`保存公开URL、HTTP状态、服务器时间、获取UTC时间和字节数；`valid_counts`记录非空数，`time_start/end`记录窗口，`error`记录失败类型。`outputs[]`记录文件名、大小和SHA-256，`script_sha256`锁定运行脚本。顶层completed表示所有源成功，completed_with_failures表示至少一个源未完整成功，均不等于科学质量已通过。

NOAA流程若成功，`messages[]`记录GRIB变量、垂直层、字节偏移、预报描述和下载状态。本次未到达该阶段。该批2026年预报数据不混入2024年研究分析。

脚本与原始测试输出仍位于上级工作区的 `scripts/` 和 `data/derived/`，不属于本独立Git仓库；本地相对链接有效，单独克隆仓库不会自动包含这些文件。

## 对实时产品的意义

已确认：无需API Key的公开接口在当前网络环境中能够返回上海位置的温湿风及短波辐射数据，可作为实时产品数据接入原型的候选。

未确认：长期可用性、访问配额及公开部署许可、上海全域空间表现、当前估计的实际精度、输入新鲜度的长期统计。两天接口返回值是模型产品，不能称作两天实测观测。

当前没有取得向下长波或人体平均辐射温度Tmrt；短波数据不等于完整人体辐射环境。没有基于这些输入生成UTCI，也没有将分钟间隔或经纬度小数位解释为模型真实时空分辨率。

下一步应针对一个已成功来源核查变量定义和许可，设计连续获取与过期判定，再补齐适用的辐射/Tmrt处理链。
